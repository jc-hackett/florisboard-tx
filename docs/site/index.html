Floris-tx

A dictation keyboard for clinicians.

Floris-tx is an Android keyboard built on FlorisBoard. Hold the mic key and talk; the words land in whatever app you are typing in.

Your voice goes to our own server, which runs under a signed business associate agreement. It is not sent to a big tech cloud. Before any AI tidies the text, names are swapped out and put back afterwards, so the AI never sees them.

It also has a cleanup button that fixes spelling and punctuation in a selection or a whole message, and a word list so it learns the names and terms you use.

It is in testing with a few clinicians now. Source on GitHub
